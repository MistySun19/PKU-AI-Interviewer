# ADR-0002 V1.0.0 先使用 kaomian 作为题库快照

## 状态

已接受

## 背景

项目需要把论文 / 仓库里的证据点连接到真实高频真实面经素材和面试拷打题。

`kaomian` 是一份已经生成好的 AI Agent 方向高频题库，来源于 `bagu-killer` 的采集、OCR、抽取、归并流水线。它比普通面经合集更适合作为高频题校准器。

## 决策

V1.0.0 先直接消费 `kaomian` 的 Markdown 题库快照。

`bagu-killer` 暂时不接入主产品流程，只作为未来题库定时更新的生产流水线。

## 后果

正面影响：

- 能快速获得真实高频题。
- 降低 V1.0.0 实现复杂度。
- 保留未来动态更新题库的方向。

代价：

- V1.0.0 题库不是实时更新。
- 检索初期可能只能做简单关键词 / 规则匹配。
- 后续需要把 `kaomian` 做成更好的检索索引。
