# ADR-0001 以 arXiv / GitHub 作为 V1.0.0 必要输入

## 状态

已接受

## 背景

v0.0.1 的核心定位是项目深挖压力面试官。当时的输入设想偏向用户手填项目描述。

后续讨论发现，如果系统只依赖用户摘要，容易退化成“ChatGPT 根据项目简介生成题”。真实面试官会看论文、仓库、代码、笔试和具体实现，因此 V1.0.0 需要把一手材料作为主入口。

## 决策

V1.0.0 的必要输入二选一：

- arXiv 链接
- GitHub 仓库链接

JD 是可选输入，用来做岗位偏置。

用户手填项目描述只能作为兜底补充，不作为主入口。

## 后果

正面影响：

- 问题有证据来源。
- 更像认真面试官 / reviewer。
- 更容易和普通 AI 面试产品拉开差异。

代价：

- 需要做材料抓取和解析。
- arXiv PDF / HTML 解析会有不稳定情况。
- GitHub 仓库太大时需要做文件筛选。
