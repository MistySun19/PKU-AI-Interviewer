# 工作日志体系

本项目的工作日志用于保存思考和调研脉络，不等同于最终产品文档。

## 当前工作日志

- `interview-worklog.md`: 用户访谈记录。
- `VERSION_WORKLOG.md`: 版本演化记录。
- `user-research.md`: 用户需求调研。
- `github-competitor-research.md`: GitHub 竞品调研。

## 记录原则

- 原始观点和产品启发分开写。
- 不把访谈观点伪装成统计结论。
- 对重要判断标注来源：访谈、竞品、项目文档、个人假设。
- 当新结论推翻旧结论时，不删旧结论，而是在版本工作日志里解释演化。

## 新增调研记录格式

```markdown
# 调研主题

## 问题

## 结论

## 证据

## 对产品的影响

## 仍不确定的点
```

## 什么时候整理成正式文档

当某个结论连续出现 3 次以上，或者直接影响 V1.0.0 架构时，应整理进入：

- `V1.0.0_PLAN.md`
- `AGENTS.md`
- `docs/adr/`
